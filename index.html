Theorems

Definition 16.1 · graph↗

A graph G is a finite set V(G) of vertices with a set E(G) of two-element subsets of V(G), the edges. The edge {x, y} is written xy. The degree deg(x) is the number of edges at x.

Proposition 16.1 · handshakes↗

\(\displaystyle\sum_{x\in V(G)} \deg(x) = 2\,|E(G)|.\)

Proposition 16.2↗

Every graph has an even number of vertices of odd degree.

Definition 16.2 · subgraph↗

H is a subgraph of G when V(H) ⊆ V(G) and E(H) ⊆ E(G).

Theorem 16.1 · bipartite↗

A graph is bipartite if and only if it contains no odd cycle.

Definition 16.3 · complement↗

The complement Ḡ has the same vertices as G, and xy is an edge of Ḡ exactly when it is not an edge of G.

Euler & Hamilton

Euler: step through Algorithm 5.14 with ◀ ▶. Trace it: tap vertices to walk a route. Hamilton: search + Ore/Dirac check. Vertices are numbered as in Keller–Trotter.

Theorems

KT Theorem 5.13 · Euler↗

A graph (with no isolated vertices) is eulerian if and only if it is connected and every vertex has even degree.

Euler trails · consequence↗

A connected graph has an Euler trail that is not a circuit exactly when it has two vertices of odd degree; the trail starts at one and ends at the other.

KT Algorithm 5.14 · Eulerian Circuit Finder↗

Start with C = (1). Repeatedly take the first vertex of C with an unused edge, walk from it always to the smallest-labelled neighbour along an unused edge until stuck, and splice that walk into C. Stuck somewhere other than where you started? That vertex has odd degree.

Theorem 16.2 · Ore↗

If G has n > 2 vertices and deg(x) + deg(y) ≥ n for every two nonadjacent vertices x, y, then G is Hamiltonian.

KT Theorem 5.19 · Dirac↗

If G has n ≥ 3 vertices and every vertex has at least ⌈n/2⌉ neighbours, then G is Hamiltonian.

Theorem 16.3 · hypercubes↗

For n ≥ 2 the hypercube Qₙ is Hamiltonian.

Trees & Kruskal

Tree?: verdict and reason. Unique path: tap two vertices.

Theorems

Definition 16.4↗

A tree is a connected graph that contains no cycles. A forest is a graph that contains no cycles.

Proposition 16.3↗

A tree with n vertices has n − 1 edges.

Corollary 16.1↗

A forest with n vertices and c components has n − c edges.

Lemma 16.1↗

A tree with more than one vertex has a vertex of degree 1 (a leaf).

KT Proposition 12.4 · exchange principle↗

In a spanning tree T there is a unique path between any two vertices x, y. If xy is an edge not in T, adding it and removing any edge of that path gives another spanning tree.

Kruskal's algorithm

Tap a weight to edit it. ▶ decides one edge at a time.

KT Algorithm 12.8 · Kruskal↗

Sort the edges so w(e₁) ≤ w(e₂) ≤ … ≤ w(eₘ). Start with S = ∅. While |S| < n − 1, add the next edge eⱼ for which S ∪ {eⱼ} has no cycle.

Planarity & Colouring

Drag vertices to remove crossings. Faces are counted once there are none.

Theorems

KT Theorem 5.33 · Euler's formula↗

Let G be a connected planar graph with n vertices and m edges. Every planar drawing of G has f faces, where \(n - m + f = 2\).

KT Theorem 5.34↗

A planar graph on n ≥ 3 vertices has at most 3n − 6 edges.

No triangles↗

If a planar graph on n ≥ 3 vertices has no triangles, every face has at least 4 edges, so 4f ≤ 2m and m ≤ 2n − 4.

KT Theorem 5.35 · Kuratowski↗

A graph is planar if and only if it does not contain a subgraph homeomorphic to K₅ or K₃,₃.

Colouring

Paint: tap a vertex to change its colour. Or use Greedy / Fewest colours.

Definition 16.5↗

The chromatic number χ(G) is the smallest k for which G has a proper k-colouring.

Proposition 16.5↗

If H is a subgraph of G, then χ(H) ≤ χ(G).

Theorem 16.4↗

If G has largest degree Δ, then χ(G) ≤ Δ + 1.

Theorem 16.5 · Brooks↗

If G is connected and is neither a complete graph nor an odd cycle, then χ(G) ≤ Δ.

KT Theorem 5.38 · Four Colour Theorem↗

Every planar graph has chromatic number at most four.

Theorems

Fact 6.1 · multiplication principle↗

If a list of length n has a₁ choices for the first entry, a₂ for the second, …, there are a₁·a₂·⋯·aₙ lists. With repetition from n things: \(n^k\) lists of length k.

Fact 6.4 · k-permutations↗

\(P(n,k) = n(n-1)\cdots(n-k+1) = \dfrac{n!}{(n-k)!}\) non-repetitive lists of length k from n elements.

Fact 6.5 · subsets↗

\(\dbinom{n}{k} = \dfrac{n!}{k!\,(n-k)!}\) for 0 ≤ k ≤ n (and 0 otherwise).

Fact 6.8 · multisets↗

The number of k-element multisets from an n-element set is \(\dbinom{k+n-1}{k} = \dbinom{k+n-1}{n-1}\).

Fact 6.9 · multiset permutations↗

A multiset of n elements with multiplicities p₁, …, pₖ has \(\dfrac{n!}{p_1!\,p_2!\cdots p_k!}\) permutations.

Theorem 6.6 · binomial theorem↗

\((x+y)^n = \sum_{k=0}^{n} \binom{n}{k} x^{n-k} y^k.\)

Fact 6.7 · inclusion–exclusion↗

\(|A\cup B| = |A| + |B| - |A\cap B|\).

Facts 6.2, 6.3 · addition & subtraction↗

Disjoint pieces add up. And if X ⊆ U then \(|\overline{X}| = |U| - |X|\): sometimes counting what you don't want is easier.

Probability

Pick events A and B, or tap cells to build your own. Condition on B greys out everything outside B.

Theorems

Fact 7.1↗

If all outcomes in S are equally likely, the probability of an event E ⊆ S is \(p(E) = \dfrac{|E|}{|S|}\).

Definition 7.1 · mutually exclusive↗

A and B are mutually exclusive if A ∩ B = ∅: they never happen together.

Fact 7.2↗

\(p(A\cup B) = p(A)+p(B)-p(A\cap B)\), and \(p(\overline{A}) = 1 - p(A)\).

Definition 7.2 · Fact 7.3 · conditional↗

p(A | B) is the probability of A given that B has happened: \(p(A\mid B) = \dfrac{p(A\cap B)}{p(B)}\), so \(p(A\cap B) = p(A\mid B)\,p(B)\).

Definition 7.3 · independent↗

A and B are independent if one happening doesn't change the probability of the other: p(A) = p(A | B) and p(B) = p(B | A). Equivalently p(A ∩ B) = p(A)·p(B).

Definition 7.4 · distributions↗

When outcomes are not equally likely, give each outcome xᵢ a probability p(xᵢ) ≥ 0 with total 1; p(E) is the sum over the outcomes in E.

Bayes' formula

Move the sliders.

Fact 7.4 · Bayes' formula↗

If S = S₁ ∪ S₂ with S₁ ∩ S₂ = ∅ and E ⊆ S, then \(p(S_1\mid E) = \dfrac{p(S_1)\,p(E\mid S_1)}{p(S_1)\,p(E\mid S_1) + p(S_2)\,p(E\mid S_2)}.\)

Expected value

KT 10.4 · expectation↗

\(E(X) = \sum_{x\in S} X(x)\,P(x)\), the expectation (mean, expected value) of X.

KT Proposition 10.17 · linearity↗

\(E(X_1 + \cdots + X_n) = E(X_1) + \cdots + E(X_n)\), always, even when the Xᵢ are dependent.
